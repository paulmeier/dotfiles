#+title: dotfiles

Doom Emacs, zsh and Starship. Nothing else is tracked (see =.gitignore=,
which is an allowlist).

* Rules
This repo is public.
- No secrets or personal identifiers in tracked files. Secrets live in
  Proton Pass; tracked files hold only =pass://Vault/Item/field=
  references.
- Machine-specific settings go in untracked files:
  - =~/.zshrc.local=, sourced at the end of =.zshrc=
  - =~/.config/doom/local.el=, scaffolded by =M-x my/write-local-template=
  - =DOTFILES_LOCATION= (e.g. =home=, =work=) in =~/.zshrc.local= tells
    Doom which machine it's on until =local.el= sets =my-location=

* Install
#+begin_src bash
brew install stow starship   # plus the Proton Pass CLI (pass-cli)
git clone git@github.com:paulmeier/dotfiles.git ~/dotfiles
cd ~/dotfiles && stow .
pass-cli login
#+end_src

Doom snippets: [[https://github.com/doomemacs/snippets]]

* Secrets (Proton Pass)
Proton Pass is the source of truth. =~/.config/zsh/secrets.env= (tracked)
lists which items become environment variables, as =pass://= references.
=pp-sync= fetches them and writes a managed block of exports into
=~/.zshrc.local= (untracked, mode 600), so every shell has them. Run it
again after changing a secret.

| Command              | Effect                                          |
|----------------------+-------------------------------------------------|
| =pp-sync=            | Refresh the secrets block in =~/.zshrc.local=   |
| =pp <Item> [field]=  | Print one field (default =password=)            |
| =ppc <Item> [field]= | Copy one field; clipboard clears after 45s      |

SSH keys come from the Proton Pass SSH agent
(=~/.ssh/proton-pass-ssh-agent.sock=).

* Emacs + Proton Pass
[[https://github.com/paulmeier/proton-pass.el][proton-pass.el]] (my package, loaded via =packages.el=), configured in =config.el= under
"Secrets (Proton Pass)":
- an auth-source backend (=proton-pass= in =auth-sources=): map hosts to
  items in =proton-pass-auth-source-alist=
- =(proton-pass-get "pass://...")= for use in config code
- =SPC P P= opens a pass.el-style vault browser (=w= copy, =e= edit,
  =r= rename, =d= trash, ...)
- =SPC P= menu: copy, insert/generate/edit/rename/trash items, switch vault
- sets =SSH_AUTH_SOCK= to the Proton Pass agent so magit uses keys stored
  in Pass
